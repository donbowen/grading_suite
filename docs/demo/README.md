# Interactive fictional demos

Open `index.html` directly in a modern browser. No installation, server, account, model calls, or network access is needed. Choose **Transcription desk** or **Grading desk** in the top bar. If your browser blocks storage for local files, ask your agent to serve this folder on localhost.

- **Transcription:** replace `[UNCLEAR]` with `third`, then select **Accept & next**. The queue advances; return to TEST_001 to inspect the saved correction. Drafts save separately.
- **Grading:** select **Revise question-wide rule…** to preview all four scores, then **Apply to all 4 answers**. Two scores change and all affected reviews reopen. This is an explicit, deterministic scoring example. Real changes requiring judgment need agent regrading.
- Edits persist in this browser's local storage. **Reset demo** clears only this demo's records. These public demos are illustrative; production apps should use durable server-side saves as required by the prompts.

Every submission, answer, exam question, and scan representation here is invented. No real student work, real scores, or answer keys are included. The scan panel uses a typeset handwriting-style facsimile, not a photograph. The production apps are generated by your agent from the prompts; these demos show the intended interactions without implementing the full production workflow.

The README animations were captured from this working demo. A GIF is an animation; open the HTML for interactive controls.
